LOFT CAFE — сайт-візитка

Як запустити: відкрийте index.html у браузері або відкрийте папку у VS Code та використайте Live Server.
Файли: index.html, style.css, script.js, images/.
У сайті використані надані фотографії, розділені на окремі зображення.
Рейтинг 4,7, адреса, телефон і графік роботи внесені за наданою інформацією.
Повне меню та ціни не додані, бо їх не було в наданих даних.
